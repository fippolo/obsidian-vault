automated planning is an important problem solving activity which consists in synthesizing a sequence of actions performed by an agent that leads from an initial state of the world to a given target state (goal)
Given:
- initial state
- a set of actions you can perform
- a state to achieve
Find:
- a plan: a partiallu or totally ordered set of actions needed to achieve the goal from the initial state

planning is natural for a human being but it is difficult for a machine

An automated planner is an intelligent agent that operates in a certain domain, it operates before trying to achieve the task, the domain is described by:
- a representation of the state
- a representation of a goal
- a formal description of the executable actions (also called operators) in terms of precondition and effects
it dynamically defines the plan of actions needed to reach the goal from the initial state. we will see in this course only offline planners.
the actions that the planner chains are only the actions that the executer can perform.
