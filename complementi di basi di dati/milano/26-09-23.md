automated planning is an important problem solving activity which consists in synthesizing a sequence of actions performed by an agent that leads from an initial state of the world to a given target state (goal)
Given:
- initial state
- a set of actions you can perform
- a state to achieve
Find:
- a plan: a partiallu or totally ordered set of actions needed to achieve the goal from the initial state

planning is natural for a human being but it is difficult for a machine

An automated planner is an intelligent agent that operates in a certain domain, it operates before trying to achieve the task, the domain is described by:
- a representation of the state
- a representation of a goal
- a formal description of the executable actions (also called operators) in terms of precondition and effects
it dynamically defines the plan of actions needed to reach the goal from the initial state. 
the actions that the planner chains are only the actions that the executer can perform.

### Planning techniques

- Deductive planning/ planning as search/ linear planning in foundations of AI
- nonlinear planning
	- Partial Order Planning (POP)
- hierarchical planning
- conditional planning
- graph-based planning
- planning for robotics paths
- planning as emergent behavior: Swarm intelligence
- Reinforcement Learning (to learn a policy)

if there is not a chain of actions that can be performed to achieve the goal planning will fail

### Genetic and evolutionary algorithms
genetic algorithms are inspired by the natura evolution and have been developed in the 70s by john holland
- we start from an initial random individuals through specific laws
- fitness ensures that only the best individuals are kept
- mutation: new elements are introduced randomly
-  cross over combines good parent solutions
- fitness is not always easy to define
- these algorithms are useful when a model of the problem is hard to be defined
