### Machine learning tasks: classification, regression, clustering

**Classification** is a supervised learning task where a model learns a mapping from input variables XX to a **discrete/categorical output** yy, such as a label or class. Classification can be binary, multi-class, or multi-label. Performance is often measured using **classification accuracy**, the percentage of correctly classified examples.

**Regression** is also supervised learning, but the output is a **continuous numerical value**, such as an amount or size. Regression can involve multiple inputs, called **multivariate regression**, or time-ordered inputs, called **time-series forecasting**. Since the prediction is numerical, performance is evaluated through prediction error, for example **RMSE**.

**Clustering** is the main **unsupervised learning** task. It organizes unlabeled data into groups whose elements are similar. In **hard clustering**, each object belongs to exactly one group; in **soft/fuzzy clustering**, an object can belong to several groups. A common hard-clustering method is **k-means**.

### Symbolic vs. sub-symbolic learning

The slides contrast **symbolic learning**, such as decision trees and Prolog rules, with **sub-symbolic learning**, such as artificial neural networks. Symbolic methods represent knowledge explicitly through interpretable rules. For example, a decision tree can learn rules such as “if a hotel has three stars, suggest it” or “if it has two stars and is close to the center, suggest it.”

### Artificial neurons and perceptrons

Artificial neurons were inspired by biological neurons, with an early mathematical model proposed by **McCulloch and Pitts in 1943**. A neuron receives inputs, multiplies them by weights, computes a **weighted sum**, and applies an **activation function** to generate an output.

A simple **perceptron** with two inputs computes something like

y=HS(w1x1+w2x2−θ)y = HS(w_1x_1+w_2x_2-\theta)

and activates when

w1x1+w2x2−θ>0.w_1x_1+w_2x_2-\theta>0.

Geometrically, this produces a **linear decision boundary** that separates one class from another.

Page 45 illustrates this with an **AND gate**: the weights and threshold are chosen so that only the input (1,1)(1,1) produces output 1. The perceptron therefore “learns” a straight-line separation between the positive and negative examples.

### Multi-layer neural networks

A single perceptron can only represent **linear separations**, so more complex concepts require networks containing multiple neurons and layers. In neural networks, unlike symbolic systems, knowledge is not stored as explicit rules: it is encoded implicitly in the network structure and connection weights.

The slides illustrate increasing expressive power:

- **Three-layer networks** can represent **convex decision regions**. Increasing the number of hidden neurons allows more boundaries to be combined.
    
- **Four-layer networks** can represent regions of much more general shapes, including multiple disconnected regions.
    

The **universal approximation theorem** states that a feed-forward neural network with one hidden layer and a finite number of neurons can approximate any continuous function to a desired accuracy. However, the theorem does **not** tell us how many neurons/layers to choose, which activation functions to use, or how best to train the network. More sophisticated neurons, architectures, nonlinear activation functions such as the sigmoid, and learning algorithms were developed especially from the 1980s onward.

### Deep learning

**Deep learning** refers to models using neural networks with many neurons and many layers. Such networks can learn complex functions and automatically identify useful features from data. Training them is computationally expensive.

An important idea is **hierarchical feature learning**: lower layers learn simpler features, while deeper layers combine them into progressively more abstract and complex representations. The representation is therefore distributed across multiple layers.

### Foundation models

Pages 54–55 introduce **foundation models** as a base layer of modern AI. They are trained at very large scale on broad and diverse datasets involving areas such as text, code, and images. They typically use **transformer architectures**, whose self-attention mechanism can model relationships across long sequences. A single pretrained model can then be adapted to many downstream tasks through **fine-tuning or prompting**.

This differs from traditional narrow AI: traditional systems are usually built for one task, often trained from scratch, and require task-specific labeled datasets. Foundation models are pretrained broadly, reused across tasks and domains, and can perform **few-shot or zero-shot** tasks.

### Agentic AI

Pages 56–57 describe **agentic AI**, where AI does more than produce an answer: it can work toward a goal through a repeated cycle. The main loop is:

**Observe → Plan → Act → Reflect.**

The system first gathers context, then breaks the goal into steps, performs actions using tools or APIs, evaluates the result, and adjusts its plan if necessary. Example applications include coding agents, research assistants, workflow automation, and customer-support agents.

### Automated planning

Finally, **automated planning** is the problem of finding a sequence of actions that takes an agent from an **initial state** to a desired **goal state**.

The planning problem is defined by an initial state, the available actions, and the goal. The output is a **plan**, meaning a partially or totally ordered collection of actions that achieves that goal.
