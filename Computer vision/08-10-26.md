### Discrite approximation of the gradient
a 1d signal could just be a row of pixels on a image, we can simply measure the change using subtraction in a discrite signal
we can both calculate the backwords and forward differences
![[Pasted image 20261008152739.png]]
**Backwards:**

$\frac{\partial I(x,y)}{\partial x} \cong I_x(i,j) = I(i,j) - I(i,j-1)$

$\frac{\partial I(x,y)}{\partial y} \cong I_y(i,j) = I(i,j) - I(i-1,j)$

**forwards:**

$\frac{\partial I(x,y)}{\partial x} \cong I_x(i,j) = I(i,j+1) - I(i,j)$

$\frac{\partial I(x,y)}{\partial y} \cong I_y(i,j) = I(i+1,j) - I(i,j)$

we can estimate the magnitude using different approximations:
$\lVert \nabla I \rVert = \sqrt{(I_x)^2 + (I_y)^2}$

$\lVert \nabla I \rVert_{+} = \lvert I_x \rvert + \lvert I_y \rvert$

$\lVert \nabla I \rVert_{\max} = \max\left(\lvert I_x \rvert, \lvert I_y \rvert\right)$

the best way to detect edges is to use the max approximations because it gives the most isotropic response, meaning that if you have orizontal vertical or oblique edge the response is always H:
