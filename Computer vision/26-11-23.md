### Neural machine translation
encoder RNN produces an encoding of the source sentence
decoder RNN is a language model that generates target sentence, conditioned on encoding
### attention
the attention methods modifyies this and instead of focusing on the last word, we use all the input words weighted (multiplying with the other input states giving us an unbounded attention score and then softmax normalizes these scores)
