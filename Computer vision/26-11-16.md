### grouped convolution
**ResNeXt extends ResNet by splitting each bottleneck block into \(G\) parallel branches**, following a **split–transform–merge** design.
- Each branch applies the same sequence: \(1×1 \rightarrow 3×3 \rightarrow 1×1\) convolutions, with internal width \(d\).
- Branch outputs are summed together and added to the original input through a residual connection.
- The number of branches \(G\), called **cardinality**, is a new hyperparameter.
- By choosing \(d\) appropriately, a \(G×d\) ResNeXt block can have computational complexity similar to the original ResNet block.
The slide leaves open how to choose \(d\).
